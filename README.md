# JudoNOW

Trainingsseite vom Weißgurt bis zum 2. Dan. Auf der Startseite meldest du dich an. Danach kommen deine Ziele, dein Gürtel, dein freigeschalteter Plan und der Start. Klammern ab Gelb, Würgegriffe ab Orange. Techniknamen stehen japanisch, zum Beispiel Kesa Gatame. Die Lehrfilme sind öffentliche YouTube-Filme, vor allem von der Kodokan. Unter Filme laufen die Attacken der Reihe nach, unter Workout findest du Aufwärmen vor dem Judo und HIIT (mit oder ohne Matte), unter Karten ordnest du Namen und Beschreibungen zu. Vom iPhone-Homescreen läuft die App als PWA auch offline für die gespeicherten Seiten. Ein Clerk-Konto speichert Ziele, Gürtel und welche Würfe du schon kannst.

Lege die Clerk-Schlüssel in `.env.local` ab. Die Namen stehen in `.env.example`.

```bash
npm install
npm run dev
```
