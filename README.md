# JudoNOW

Trainingsseite vom Weißgurt bis zum 2. Dan, mit den Zwischenfarben Weiß-Gelb, Gelb-Orange und Orange-Grün. Zuerst das Motto, dann der Gürtel, dann die Übungen. Klammern ab Gelb, Würgegriffe ab Orange. Japanische Namen stehen in deutscher Lesart, zum Beispiel Kesa Gatame. Die Lehrfilme sind öffentliche YouTube-Filme, vor allem von der Kodokan. Unter Filme laufen die Attacken der Reihe nach, unter Karten ordnest du Namen und Beschreibungen zu. Ein Clerk-Konto speichert, welche Würfe du schon kannst.

Lege die Clerk-Schlüssel in `.env.local` ab. Die Namen stehen in `.env.example`.

```bash
npm install
npm run dev
```
