# JudoNOW

Trainingsseite vom Weißgurt bis zum 2. Dan, mit den Zwischenfarben Weiß-Gelb, Gelb-Orange und Orange-Grün. Zuerst das Motto, dann der Gürtel, dann die Übungen. Klammern ab Gelb, Würgegriffe ab Orange. Japanische Namen stehen in deutscher Lesart, zum Beispiel Kesa Gatame. Die Lehrfilme sind öffentliche YouTube-Filme, vor allem von der Kodokan. Ohne Anmeldung.

```bash
npm install
npm run dev
```
