# JudoNOW

Trainingsseite vom Weißgurt bis zum 2. Dan. Auf der Startseite meldest du dich an. Danach kommen deine Ziele, dein Gürtel, dein freigeschalteter Plan und der Start. Klammern ab Gelb, Würgegriffe ab Orange. Techniknamen stehen japanisch, zum Beispiel Kesa Gatame. Die Lehrfilme sind öffentliche YouTube-Filme, vor allem von der Kodokan. Unter Filme laufen die Attacken der Reihe nach, unter Workout findest du Aufwärmen vor dem Judo und HIIT (mit oder ohne Matte), unter Karten ordnest du Namen und Beschreibungen zu. Unter Prüfung läuft ein Probetest, unter Suche findest du zum Beispiel alle Seoi-Würfe. Impressum und Datenschutz liegen in der Fußzeile. Vom iPhone-Homescreen läuft die App als PWA auch offline für die gespeicherten Seiten. Ein Clerk-Konto speichert Ziele, Gürtel, Häkchen, XP, Serie und das Prüfungsdatum. Trainergruppen liegen in den privaten Kontodaten und brauchen den Clerk-Geheimschlüssel auf dem Server.

Lege die Clerk-Schlüssel in `.env.local` ab. Die Namen stehen in `.env.example`.

```bash
npm install
npm run dev
```
