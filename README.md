# JudoNOW

Trainingsseite vom Weißgurt bis zum 2. Dan. Zuerst das Motto, dann der Gürtel, dann die Übungen: Würfe, Haltegriffe und ab Blau Würgegriffe, Klammern und Entkommen. Japanische Namen stehen in deutscher Lesart, zum Beispiel Kesa Gatame. Die Lehrfilme sind öffentliche YouTube-Filme, vor allem von der Kodokan. Ohne Anmeldung.

```bash
npm install
npm run dev
```
